# Clearview mock-up

Open the shared mock-up: https://domeasarnie-star.github.io/Clearview-preview/

This repository contains the compiled Demo preview of an environmental clutter screening app. It is a working prototype for feedback, with draft notices and provisional scoring rules. Live AI analysis and browser dictation are disabled. No API key or server function is included.

To try it:

1. Open the link above and select **Download example image**. The image contains generated coloured shapes, with no personal photograph or data.
2. Upload the example image and select **Analyse image** for fixed synthetic findings, or **Use manual scoring** to enter your own score and flags.
3. Add professional notes, choose an override if needed, enter its reason, and confirm the review.
4. Select **Prepare PDF**, then **Download PDF**. Use **New Assessment** to clear the tab.

The Demo findings do not describe the uploaded image. Photos and typed notes are processed in the current tab, and the PDF is generated on your device. GitHub hosts the website and may log page requests under its own terms. Downloaded PDFs stay on your device. Use synthetic images and notes for feedback.

You can also [download the synthetic example directly](example-room.png). This preview is publicly accessible. The application source and project documents are maintained separately in the owner's private repository. Updates are published after verification; this repository has no live-analysis credentials or cross-repository automation token.
